Generate / reset login credentials

This runs entirely in your browser — nothing is sent anywhere. Your plain password is never stored; only a random salt and its PBKDF2 hash go into the database.

Day-to-day password resets don't need this page — once you're set up, just log in and use Settings → Change password inside the app. Use this page only for the very first setup, or as a fallback if you're ever locked out and need to reset directly in the database.

2. Set this one Worker secret (only needed once, ever)

SESSION_SECRET
SESSION_SECRET is the only credential still stored as a Worker secret — it signs login sessions, not your password. Set it once in Settings → Variables and Secrets and never touch it again. Regenerating it later logs out everyone with an active session.
